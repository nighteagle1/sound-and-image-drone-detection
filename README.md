# Обнаружение дронов по звуку и изображению

Учебная демонстрация: веб-приложение, которое в браузере обнаруживает дронов по звуку
(микрофон или аудиофайл) и по изображению (камера или видеофайл). Два независимых режима,
одновременно работает один. Инференс идёт через ONNX Runtime, PyTorch не нужен.

Это не полевая система: надёжность в реальных условиях (ветер, большие расстояния) не гарантируется.

## Требования

- Python 3.11 или новее.
- Raspberry Pi 4/5 с 64-bit Raspberry Pi OS (Bookworm) или Windows 10/11.
- Интернет нужен только для установки пакетов Python при первом запуске. Модели лежат в репозитории.

## Запуск

Windows (двойной щелчок по файлу или в терминале):

```bash
run.bat
```

Raspberry Pi / Linux:

```bash
git clone <адрес репозитория>
cd sound-and-image-drone-detection
./run.sh
```

Скрипт сам создаёт `.venv`, ставит зависимости и открывает браузер на `http://127.0.0.1:8000`.
Если на Raspberry Pi не хватает системных пакетов, `run.sh` напечатает точную команду
`sudo apt install libportaudio2 libsndfile1` и остановится; сам `sudo` он не запускает.

Параметры (передаются скрипту): `--port N`, `--no-browser`, `--host 0.0.0.0`.
По умолчанию сервер слушает только `127.0.0.1`. С `--host 0.0.0.0` страница открывается с других
устройств, но она без авторизации и даёт доступ к камере и микрофону этого устройства, поэтому
включайте это только в доверенной сети.

## Как пользоваться

1. Выберите вкладку «Звук» или «Изображение». Смена вкладки останавливает текущий режим.
2. Выберите источник: устройство (микрофон, камера) или файл.
3. Настройте порог и нажмите «Старт». Файл проигрывается сервером в реальном времени и в конце останавливается.
4. Смена источника: «Стоп», выбор, «Старт». Перезапускать сервер не нужно.

Подсказки для показа:

- Звуковая модель обучена на датасете, где «не дрон» в основном бытовые и речевые звуки. Возможны ложные
  срабатывания (разговор, музыка, пылесос) и пропуски тихого игрушечного дрона. Порог настраивается ползунком.
- Подносите дрон близко к микрофону; индикатор включается после двух окон подряд выше порога и выключается
  после двух ниже, а на графике показана сырая вероятность за 30 с.
- Для изображения порог уверенности по умолчанию 0.25; NMS IoU фиксирован 0.45.
- Ожидаемый FPS изображения на Pi 4 порядка 15–20 по заявлению автора модели; проверяется отдельно.

## Модели и лицензии

Подробности и форматы входа и выхода: `models/README.md`.

| Режим | Модель | Лицензия |
|---|---|---|
| Звук | [AntoineNaccache/drone-audio-detector](https://huggingface.co/AntoineNaccache/drone-audio-detector), `drone_classifier_aug_mixed.pt`, сконвертирована в `models/drone_audio.onnx` | MIT |
| Изображение | [engdarwish/drone-detection-yolov5](https://huggingface.co/engdarwish/drone-detection-yolov5), `best.onnx` | MIT |

Заявленные авторами метрики (F1 0.9996 для звука, mAP50 99% для изображения) получены на их данных
и на показе не гарантируются.

## Как заменить модель

Положите свой `.onnx` в `models/` и поправьте путь в `config.yaml` (`audio_model`, `vision_model`).
Звуковая модель должна принимать лог-мел `(1, 1, 64, T)` и возвращать логит `(1, 1)`.
Модель изображения — YOLOv5 с выходом `(1, N, 5 + nc)` и фиксированным или динамическим квадратным входом;
размер входа берётся из модели. Параметры признаков звука заданы в `src/dronedetect/audio/features.py`.

## Как повторить экспорт звуковой модели на Kaggle

Нужен установленный и авторизованный `kaggle` CLI. В `tools/kaggle_export/kernel-metadata.json` укажите свой
идентификатор `<ваше имя пользователя на Kaggle>/drone-audio-onnx-export` (имя видно в `kaggle config view`), затем:

```bash
kaggle kernels push -p tools/kaggle_export
kaggle kernels status <имя пользователя>/drone-audio-onnx-export
kaggle kernels output <имя пользователя>/drone-audio-onnx-export -p tools/kaggle_export/out
```

Скрипт загружает веса со `strict=True`, сверяет вероятности ONNX и PyTorch (допуск 1e-4) и сохраняет
`drone_audio.onnx` и `audio_golden.npz`. Скопируйте их в `models/` и `tests/data/`.

## Разработка и тесты

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest -v
.venv/Scripts/python -m dronedetect --no-browser
```

На реальной Raspberry Pi работа проверяется отдельно: `git clone`, `./run.sh`.
